# Python_Music
minimalist YT music player in terminal. Search a song and play it, directly. No API needed.

## installation

# PC
sudo apt install ffmpeg yt_dlp

python music.py

---

# Phone (termux)

pkg update

pkg install mpv

pip install yt-dlp


python music_termux.py
